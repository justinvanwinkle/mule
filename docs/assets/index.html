How to read this report

Each dot compares median times for the same scenario and input. Ratios above 1× mean faster than the baseline. The logarithmic axis gives equal space to equal multiplicative changes. Each runtime has its own lane within each scenario. Baseline points are implicit at 1×. Failures contribute no speedup.

Preparation, warmups, output, and result checks are excluded from kernel time. Whole-process time includes startup, preparation, warmups, and measured calls; compilation is separate. Each ratio compares the same scenario and input. σ describes sample variation, not a confidence interval. Short kernels can be dominated by measurement overhead; increase workload size before drawing conclusions.
