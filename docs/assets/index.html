How to read this report

Vertical bars show median elapsed time in milliseconds for the same scenario and input. Shorter bars mean faster execution. Each scenario has an independent linear vertical scale starting at zero. Compare runtimes within a panel, not bar heights across panels. The baseline appears alongside every other runtime. Unavailable or failed results have no bar.

Preparation, warmups, output, and result checks are excluded from kernel time. Whole-process time includes startup, preparation, warmups, measured calls, and output; compilation is separate. σ describes sample variation, not a confidence interval. Short kernels can be dominated by measurement overhead; increase workload size before drawing conclusions.
